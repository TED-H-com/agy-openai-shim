What it connects串接方式

Three parts, one local endpoint.

三個部分，一個本機端點。

01

Chat-completions interface

聊天介面

Accept OpenAI-style chat requests and return normal or streamed responses through the CLI bridge.

接收 OpenAI 格式的聊天請求，透過 CLI 橋接回傳一般或串流回覆。

02

Account selection

帳號選擇

Choose round-robin or fill-first selection with per-account quota cooldowns. Authenticate each account through the CLI before adding it.

選擇輪替或優先填滿策略，依帳號處理配額冷卻。加入帳號前，先透過 CLI 完成登入。

03

Local operation

本機執行

Run the standard-library Python server directly or use the supplied systemd user-service template. The default bind is loopback.

直接執行使用標準函式庫的 Python 伺服器，或使用隨附的 systemd 使用者服務範本。預設只綁定本機迴圈位址。

Start here從這裡開始

Install the CLI, then connect the client.

先準備 CLI，再串接客戶端。

需要 Python 3.10 以上，以及已安裝、已登入的 agy CLI。複製範例設定、列出帳號目錄，再依 README 啟動伺服器。

Current scope目前範圍

A focused bridge, available as source.

範圍明確的橋接工具，以原始碼提供。

An early utility with no tagged release. Core client code is vendored from soyelmismo/hermes-antigravity-subscription under MIT; this repository adds the pool, server wrapper and systemd packaging.

尚無 tag 發行版的早期工具。核心客戶端採用 soyelmismo/hermes-antigravity-subscription 的 MIT 程式碼；這個儲存庫加入帳號池、伺服器封裝與 systemd 設定。

Works today

目前可用

  • Chat-completions, model-list and health endpoints are present in the source.
  • 原始碼提供聊天完成、模型清單與健康檢查端點。
  • Both streamed and non-streamed replies, account selection and error mapping.
  • 支援串流與非串流回覆、帳號選擇及錯誤對應。

Limits and not yet

限制與尚未完成

  • This is an OpenAI-compatible subset, not the complete OpenAI API. Tool calls are emulated and CLI host tools are denied.
  • 這是 OpenAI 相容介面的子集，不是完整 OpenAI API。工具呼叫以模擬方式處理，CLI 的主機工具會被拒絕。
  • Requires your own authenticated CLI accounts and remains subject to their service access and quotas.
  • 需要自己已登入的 CLI 帳號，並受原服務的存取權限與配額限制。
  • Keep the default loopback deployment. The wrapper supplies no production authentication layer for public exposure.
  • 維持預設的本機部署方式；這層封裝沒有提供對外公開服務所需的正式驗證層。
